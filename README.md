# Ejemplos de funciones con `re`

Pequeño ejercicio en Python para practicar el uso de expresiones regulares con el módulo estándar `re`.

## Requisitos

- Python 3

## Ejecución

```bash
python "ejemplos_funciones_re (1).py"
```

## Contenido

El repositorio contiene un script de ejemplo: `ejemplos_funciones_re (1).py`. Puedes modificarlo para probar patrones y funciones del módulo `re`.
